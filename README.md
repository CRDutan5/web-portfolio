# Software Developer Portfolio

A modern, responsive web portfolio built with Angular and TypeScript, featuring a beautiful bento box style layout.

## Features

- **Bento Box Layout**: Modern grid-based design with varying card sizes
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices
- **TypeScript**: Type-safe development with Angular's latest features
- **Modern Design**: Beautiful gradient backgrounds and smooth animations
- **Interactive Components**: Hover effects and transitions for better UX

## Sections

- **Hero**: Eye-catching introduction with call-to-action buttons
- **About**: Professional summary with key statistics
- **Skills**: Showcase of technical expertise
- **Projects**: Featured projects with descriptions and tech stacks
- **Contact**: Easy ways to get in touch with social links

## Development

### Prerequisites

- Node.js (v22 or higher)
- npm (v10 or higher)

### Installation

```bash
npm install
```

### Development Server

```bash
npm start
```

Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.

### Build

```bash
npm run build
```

Build artifacts will be stored in the `dist/` directory.

## Customization

To customize this portfolio for your own use:

1. Update contact information in `src/app/components/contact/contact.html`
2. Modify the About section in `src/app/components/about/about.html`
3. Add your own projects in `src/app/components/projects/projects.html`
4. Update skills in `src/app/components/skills/skills.html`
5. Customize the hero section in `src/app/components/hero/hero.html`
